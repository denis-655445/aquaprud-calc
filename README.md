# Aquaprud — калькулятор кошторису ставка (Telegram Mini App)

Етап A3 (v0.8.0): прайс і налаштування — з Google Таблиці через Apps Script (`adapters/gas/`).
Поки `API_BASE` у `miniapp/js/config.js` порожній або застосунок відкрито поза Telegram — **тестовий каталог** (`data/catalog.sample.js`).
Хостинг — GitHub Pages, бекенд — Google, тому MacBook для роботи застосунку вмикати не потрібно.

## Структура

```
core/            ядро: розрахунок (calc.js), текст кошторису (format.js), геометрія схеми 2D/3D (pondgeo.js), сходинки (stairs.js),
                 укіс (slope.js), перевірка initData (auth.js), каталог з рядків таблиці (catalog.js)
adapters/gas/    бекенд на Apps Script: Code.gs, auth.gs, storage.gs + копії ядра core_auth.gs, core_catalog.gs
miniapp/         сам застосунок: index.html, css/, js/ (3D-схема — js/sketch3d.js)
data/            тестовий каталог (покриває ставки до 30 × 10 × 5 м)
tests/           тести: tests.html (браузер), run-node.js (Node.js); сходинки — stairs.tests.js (node tests/stairs.tests.js)
docs/            project_status.md (опис проєкту), stairs_math.md (математика сходинок)
```

## Перевірка на MacBook без інтернету й сервера

Відкрийте подвійним кліком `miniapp/index.html` — застосунок запрацює в браузері.
Тести: `tests/tests.html` — має бути «Усі 108 тестів пройдено»; `node tests/run-node.js` — 114 (ще 6 тестів адаптера Apps Script, лише в Node).

## Сходинки (Про-режим)

Довге натискання на заголовок «Кошторис ставка» → службова панель → «Сходинки (Про-режим)». Під схемою з'явиться лічильник «Рівні» (до 5 з дном): «+» додає сходинку, точки обирають натисканням на 2D-схемі. Прибрана «−» сходинка пам'ятається: «+» повертає її з точками й розмірами.

## Біоплато (v0.7.1)

Перемикач «Біоплато» → праворуч лічильник «− 1 +» (до 4 ділянок Bio-1…Bio-4). У рядку кожного Bio — ширина від краю ставка; довжина = сторона ставка (підставляється сама), ‹ › переносять Bio на іншу сторону, зайняті пропускаються. Суміжні Bio додають стик у куті (w₁ × w₂) — під рядками: «Додано … на стик; загальна площа …». Прибране «−» Bio пам'ятається: «+» повертає його.

## Укіс стінок

Службова панель → «Укіс стінок ставка, °»: 90° — вертикальні стінки (максимум і за замовчуванням), найменше — 30°; «−» / «+» — крок 1°, число можна ввести з клавіатури. Задається один раз і діє в усіх кошторисах; «Новий кошторис» його не скидає. Підйоми між сходинками — завжди 90°. Укіс рахується в об'ємі й плівці та видно на 2D (‹ › — «План» → «Розріз А–А» → «Розріз Б–Б»); 3D — з вертикальними стінками.

## Тема

Службова панель → «Тема інтерфейсу»: Темна (за замовчуванням) / Світла / Система (кольори Telegram).

## Прайс з Google Таблиці (етап A3)

Потрібно один раз, ~20 хв. Токен бота — з Паролів iPhone; у файли й GitHub його **не вставляти**.

1. **Таблиця.** Google Drive → папка `Aquaprud` → «Створити → Завантажити файл» → `docs/Aquaprud — Кошториси v1.xlsx` → відкрити → «Файл → Зберегти як Google Таблиці» → назва «Aquaprud — Кошториси». Назви вкладок «Прайс» і «Налаштування» не змінювати.
2. **Скрипт.** У таблиці: «Розширення → Apps Script». Відкриється редактор з файлом `Код.gs` (або `Code.gs`): замінити весь його текст вмістом `adapters/gas/Code.gs`.
3. «+» біля «Файли» → «Скрипт» → назва `auth` → вставити `adapters/gas/auth.gs`. Так само: `storage`, `core_auth`, `core_catalog`. Разом 5 файлів. Зберегти (значок дискети).
4. **Секрети.** ⚙ «Параметри проєкту» → «Властивості скрипту» → «Додати властивість»:
   `BOT_TOKEN` — токен бота; `ALLOWED_USER_IDS` — поки будь-яке число, напр. `0` (свій ID дізнаєтесь у п. 9).
5. **Дозвіл.** Редактор → вгорі вибрати функцію `checkFromEditor` → «Виконати» → Google попросить доступ до таблиці → «Дозволити» (якщо «Google не перевірив цей застосунок» — «Додатково → Перейти до проєкту»; це ваш власний скрипт). У «Журналі виконання» — «Позицій: 43…».
6. **Публікація API.** «Розгорнути → Нове розгортання» → ⚙ тип «Веб-застосунок» → «Виконувати як: Я», «Хто має доступ: Усі» → «Розгорнути» → скопіювати URL, що закінчується на `/exec`.
7. **Перевірка.** Відкрити в Safari `URL/exec?action=ping` → `{"ok":true,"api":"gas-0.8.0"}`.
8. **Застосунок.** У `miniapp/js/config.js`: `API_BASE: 'URL/exec'` → завантажити на GitHub (розділ «Оновлення»).
9. **Доступ.** Відкрити калькулятор кнопкою в боті → банер «Доступ заборонено: ваш Telegram ID 123…» → у «Властивостях скрипту» `ALLOWED_USER_IDS` = `123…` (кілька — через кому: ваш і техпрацівника). Перерозгортати не треба — відкрити калькулятор знову.
10. **Перевірка DoD.** Змінити ціну в «Прайсі» → закрити й відкрити калькулятор → нова ціна.

Як працює:
- Сервер тримає прайс у кеші 5 хв; правка клітинки в «Прайсі» / «Налаштуваннях» скидає кеш одразу. Якщо зміна не видна — у таблиці меню **Aquaprud → Оновити прайс у застосунку** (меню з'являється після перевідкриття таблиці).
- **Aquaprud → Перевірити прайс** — список помилок (текст замість числа, повтор id, невідома категорія). Ті самі помилки застосунок показує банером.
- Телефон зберігає останній отриманий прайс. Немає інтернету — калькулятор працює зі збереженим і показує дату.
- «ТЕСТ» у назві хоча б однієї активної позиції = у кошторисі «⚠️ ТЕСТОВІ ЦІНИ». Прибрали всі «(ТЕСТ)» — позначка зникає.
- Змінили код скрипту → «Розгорнути → Керування розгортаннями» → ✏️ → «Версія: Нова версія» → «Розгорнути» (URL `/exec` не змінюється). Файли `core_auth.gs` / `core_catalog.gs` — точні копії `core/auth.js` / `core/catalog.js` (тест перевіряє).

## Публікація

1. GitHub → **New repository** → назва `aquaprud-calc`, **Public** → Create.
2. **uploading an existing file** → перетягніть вміст папки (core, miniapp, data, tests, README.md) → **Commit changes**.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 хв застосунок доступний за адресою
   `https://<ваш-логін>.github.io/aquaprud-calc/miniapp/`

## Підключення до бота

BotFather → `/mybots` → `@aquaprud_bot` → **Bot Settings → Menu Button** → надіслати адресу з п. 4 → назва кнопки `Калькулятор`.

## Оновлення

1. У репозиторії: **Add file → Upload files** → перетягніть вміст нової версії (ті самі папки) → **Commit changes**. Змінені файли замінюються автоматично.
2. GitHub Pages оновлюється за 1–2 хв; браузер і Telegram можуть показувати стару версію ще до ~10 хв.
3. Якщо в Telegram довго лишається стара версія — у BotFather змініть адресу Menu Button, додавши в кінці `?v=2` (далі `?v=3` тощо).

Розробнику: після зміни файлів збільшуйте `?v=N` у `miniapp/index.html` і `CONFIG.APP_VERSION`.
